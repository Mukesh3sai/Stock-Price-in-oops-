# Publish this repository to GitHub (do not paste a made-up URL into the report)

1. Sign in to GitHub and create a **new empty repository** named `stock-price-prediction-cpp`. Choose private or public according to your course instructions. Do not initialize a second README.
2. In Windows CMD, open this extracted project folder and ensure Git is installed: `git --version`.
3. Execute:

```bat
git init
git add .
git commit -m "CSE 202 stock price prediction OOP project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/stock-price-prediction-cpp.git
git push -u origin main
```

4. **Replace `YOUR_USERNAME` with your actual GitHub username**. GitHub may request that you sign in via the browser or use a suitable authentication method.
5. Copy the real repository address shown in your browser and replace **[GITHUB REPOSITORY URL - TO ADD]** in the report and PPT.
6. If the faculty needs to review a private repository, explicitly grant the required access. A private link alone is not enough.

If you prefer not to use Git commands, use GitHub's **Add file > Upload files** in the newly created repository and upload files from this extracted folder. Do not upload .exe binaries or personal credentials.
